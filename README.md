# LinySync

Move your working setup from one Linux machine to another, whichever distro each runs. One side offers, the other picks, only the picks travel, end to end
encrypted, and an AI agent finishes the setup on the new machine.

LinySync is the Linux member of a family: [MacySync](https://macysync.vercel.app) (Mac to Mac),
[WindySync](https://github.com/Ege-BULUT/WindySync) (Windows to Windows) and
[AnySync](https://github.com/Ege-BULUT/AnySync) (any of them to any of them). It runs AnySync's engine with Linux on both ends:
only Linux devices are listed and accepted.

Status: early. `linysync` opens the window; `linysync --scan`, `--give <id>`, `--accept` and `--id` do the same from a
terminal. See [docs/DESIGN.md](docs/DESIGN.md).

## Download

The Linux build is on the [releases page](https://github.com/Ege-BULUT/LinySync/releases): `linysync-linux-x64.tar.gz`.
