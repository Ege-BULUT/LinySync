Get Liny~Sync.

One app for the old machine and the new one, whatever distro each runs.

Linuxx64 · any distro.tar.gz ↓

One program, the window and the command line together: tar -xzf linysync-linux-x64.tar.gz, then ./linysync. It needs the GitHub CLI signed in (gh auth login). The first release is not out yet; this button gets it once it is.

The window needs the usual X11 or Wayland libraries, which a desktop distro already has.
